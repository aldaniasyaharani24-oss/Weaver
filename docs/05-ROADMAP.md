# Sprint Definition of Done

Setiap Sprint dianggap selesai jika:

- Semua fitur selesai.
- Build berhasil.
- Tidak ada error TypeScript.
- Tidak ada error ESLint.
- Sudah direview.
- Sudah diuji.
- Dokumentasi diperbarui.

---

# Development Rules

Semua Sprint harus mengikuti urutan.

Tidak boleh melompati Sprint.

Jika Sprint belum selesai maka Sprint berikutnya tidak boleh dimulai.

---

# Review Process

Setiap Sprint akan melalui:

1. Planning
2. Development
3. Code Review
4. Refactor
5. Testing
6. Approval

Baru lanjut Sprint berikutnya.
