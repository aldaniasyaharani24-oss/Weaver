# Row Level Security (RLS) Policy

## Tujuan

Dokumen ini mendefinisikan aturan keamanan (Row Level Security) untuk seluruh tabel pada aplikasi Kanban AI.

Semua tabel menggunakan Row Level Security (RLS) agar setiap pengguna hanya dapat mengakses data yang menjadi haknya.

---

# Prinsip Umum

- Semua tabel mengaktifkan Row Level Security.
- User hanya dapat mengakses data yang memiliki izin.
- Seluruh operasi menggunakan auth.uid().
- Tidak ada akses anonymous.
- Semua Foreign Key mengikuti kepemilikan Workspace.

---

- Profil anggota workspace yang sama.

## DELETE

# Workspaces

## SELECT

User hanya dapat melihat workspace yang menjadi anggotanya.

## INSERT

User yang login dapat membuat workspace baru.

## UPDATE

Hanya Owner dan Admin.

## DELETE

Hanya Owner.

---

# Workspace Members

## SELECT

Semua anggota workspace dapat melihat daftar anggota.

## INSERT

Owner dan Admin dapat mengundang anggota baru.

## UPDATE

Owner dapat mengubah role.

Admin tidak dapat mengubah Owner.

## DELETE

Owner dapat menghapus siapa saja.

Admin hanya dapat menghapus Member.

Member tidak dapat menghapus siapa pun.

# Security Checklist

- RLS aktif pada semua tabel.
- Semua policy menggunakan auth.uid().
- Tidak ada akses anonymous.
- Hak akses mengikuti role (Owner, Admin, Member).
- Hak akses mengikuti kepemilikan Workspace.
- Policy dibuat terpisah untuk SELECT, INSERT, UPDATE, dan DELETE.
